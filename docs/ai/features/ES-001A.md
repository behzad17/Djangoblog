# ES-001A — Smart News Import

**Status:** Implemented (generate-only; never publishes)  
**Parent:** [ES-000](./ES-000.md)  
**Flag:** `ENABLE_EDITORIAL_STUDIO`  
**Entry:** Admin → **Editorial Studio**, or `/content-ai/editorial-studio/`

---

## Objective

First production Editorial Studio tool: paste a Swedish news URL, extract the article, run the production AI workflow, and return a structured Persian draft with metadata.

No publishing, editing, or saving in this milestone.

---

## Request lifecycle

```
Editor pastes URL
  → Content type + output mode (defaults: Auto Detect / Publish-ready News)
  → POST /content-ai/editorial-studio/api/import/
  → NewsImportService
       → extract_article_from_url (og:title / h1 / cleaned <title>; no crawler)
       → EditorialAIService.generate_draft(language='fa')
            → Pass 1: TITLE + LEAD via WorkflowOrchestrator.execute()
            → Pass 2: BODY (+ summary/category/tags) with locked TITLE/LEAD
  → Structured result (title, lead, body, summary, category, tags + metadata)
```

Generation **must** use `WorkflowOrchestrator.execute()` on each pass. There is no bypass path.
Headline and lead are generated before body.

## Result contract

| Field | Meaning |
|-------|---------|
| Title / Lead / Body | Persian draft sections |
| Short Summary | Concise Persian summary |
| Suggested Category / Tags | Editorial hints |
| Source URL / Source Name | Attribution |
| Language | Output language (`fa`) |
| Workflow Stages | Stages executed |
| Duration / Provider | Telemetry |

Metadata is editor-facing only (no intelligence / debug dumps).

---

## Errors (editor-facing)

| Case | Behaviour |
|------|-----------|
| Invalid URL | Clear validation message |
| Extraction failure | Readable extract error |
| Workflow / provider failure | Generation failed; try again |

## Out of scope

SEO · Newsletter · Fact Check · Publishing · Social · Peyvand Intelligence UI.

---

## Known limitations

- Extraction is lightweight HTML parsing (no trafilatura/newspaper); some sites may fail.
- Content-type auto-detect is heuristic (URL/title/text keywords), not an LLM call.
- Structured TITLE/LEAD/… parsing depends on the model following labelled output; mock providers return unlabeled stubs.
- No draft persistence — result is session/UI only until a later milestone.
