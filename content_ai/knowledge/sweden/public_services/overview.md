# Public Services Overview

## Summary
Public services in Sweden are split across state agencies, regions, and municipalities. Editors should name the correct level.

## Key points for editors
- State vs region vs kommun responsibilities differ.
- When unsure, prefer official agency pages over secondary blogs.
